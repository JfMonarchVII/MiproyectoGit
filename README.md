# Evidencia Git y GitHub

Durante esta actividad aprendí a utilizar Git y GitHub para controlar las versiones de un proyecto.

## Consultas realizadas

Durante la actividad realicé consultas sobre los siguientes comandos de Git:

### git init

Permite inicializar un repositorio de Git en una carpeta.

### git status

Permite consultar el estado actual de los archivos del proyecto

### git add

Permite agregar archivos o cambios al área de preparación para posteriormente realizar un commit.

### git commit

Permite guardar en el historial los cambios que fueron preparados previamente con `git add`.

### git branch

Permite administrar las ramas del proyecto.

### git remote

Permite administrar las conexiones con repositorios remotos.

### git push

Permite enviar los commits del repositorio local hacia el repositorio remoto en GitHub.
